## 商用合格に必要
1. Windowsで `python -m unittest discover -s tests -p "test*.py" -v` とGUIのsmoke / E2Eを実行。
2. 入力選択→自動提案→事前確認→実変換→保存ファイル確認を日本語パスと英語パスで確認。
3. 出力先がルート外・同一ファイル・既存ファイルの場合の安全停止、大量行、破損JSONL、文字コードを試験。
4. CSV数式注入防御により**データ値が変化したこと**を画面/結果に明示できるか確認。
5. Windows 11 DPI 100/125/150%、画面の見切れ、キー操作、再起動、保存設定、Windows Defender。
6. Store製品固有の正式Identity/ロゴの確認、MSIX生成・実機署名付き検証・WACK・更新/削除。
7. 商品価格・ライセンス・機能制限・スクリーンショット・サポート情報を確認し、販売承認を得る。

まだMSIX合格・売上予測の確証はありません。main、元のパイプライン、既存リリースを上書きしない。
